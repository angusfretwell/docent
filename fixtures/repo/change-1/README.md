# Palette

A tiny static color-palette toy. Serve the directory and press **Generate** to
mix a fresh set of random swatches — no build step, no dependencies.

## Layout

- `index.html` — the page shell
- `styles.css` — swatch grid, controls, and typography
- `src/app.js` — wiring and rendering
- `src/color.js` — hex/channel conversion and random color mixing
- `src/presets.js` — the named starter palettes
- `src/filter.js` — brightness filters over a palette
